Game Character System
Due 8/17/2026, 6:36:00 PM · 25 marks

What to build
Create a basic Game Character System to demonstrate inheritance.

Create a parent class

GameCharacter

It can contain common properties such as

Name

Health

Level

Create three child classes

Warrior

Archer

Wizard

Give each character some additional attributes and methods.

For example

Warrior → Sword Attack

Archer → Arrow Attack

Wizard → Magic Attack

Create at least one object of each character type.

Demonstrate a simple interaction where characters attack each other and their health changes.

You are not expected to create an actual game or graphical interface. The objective is to demonstrate OOP and inheritance.
